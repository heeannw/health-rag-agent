# 건강 정보·의료 혜택 AI 에이전트

RAG + 벡터DB 기반 정보 검색 에이전트와 튜닝된 건강 위험 예측 모델을 결합한
"나이·건강상태 맞춤형 건강정보/의료혜택/법제도 질의응답 챗봇"

## 프로젝트 개요

사용자가 자신의 나이, 건강상태, 생활습관을 입력하거나 자연어로 질문하면:

1. **정보성 질의** (예: "65세 이상 받을 수 있는 의료 혜택 뭐 있어?", "고혈압 관련 법 제도 알려줘")
   → RAG 파이프라인이 공공데이터·법령·복지 정보를 검색해 근거 기반으로 답변
2. **예측/평가성 질의** (예: "내 건강검진 수치로 봤을 때 위험한 편이야?")
   → 팀이 직접 튜닝한 건강 위험도 예측 모델이 스코어링 결과 제공
3. 두 결과를 에이전트가 통합해 하나의 답변으로 생성

> ⚠️ **포지셔닝 주의**: "질병 진단/확진"이 아니라 **"위험요인 스크리닝 및 정보 안내"**로 프레이밍할 것
> (의료행위 오인 방지, 논문 심사 및 서비스 안전성 측면에서 중요)

## 시스템 아키텍처

```
사용자 질문 입력
      ↓
질의 의도 분류 에이전트 (정보성 vs 예측성 판별)
      ↓                                    ↓
RAG 파이프라인                     건강위험 예측 모델
(복지·법령·건강정보 벡터 검색 + LLM)   (KNHANES·노인실태조사 튜닝 모델)
      ↓                                    ↓
          응답 통합 생성 (근거 + 예측 결합)
                      ↓
              최종 답변 제공
```
